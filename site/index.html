Hylograph Demos

Interactive examples for the Hylograph visualization libraries, ordered from foundations to full applications.

Foundations

Sigil

Type-safe HTML rendering of PureScript type signatures. Records as tables, functions as arrow chains, type variables coloured automatically.

sigil

The Hylographic Fold

Seven-chapter interactive guide to HATS trees, folds, interpreters, and coordinated highlighting — the core of how Hylograph works.

hylograph-selection
Data & Sound

Anscombe's String Quartet

Four datasets with identical statistics that sound completely different. Data sonification reveals what summary numbers hide.

hylograph-music

Force Playground

Interactive force-directed graph simulation. Toggle forces, adjust parameters, regenerate — see how n-body, link, and collision forces interact.

hylograph-simulation
Graph Analysis

The Honeycomb

Six hexagonal graphs running force simulations. Toggle edges — the change propagates to all six. Find the configuration where every path connects.

hylograph-graph

Decomposition Explorer

Biconnected components, articulation points, bridges, and the chimera skeleton. Adjacency matrices reordered to reveal block structure.

hylograph-graph
Layout & Type Systems

Layout Gallery

Hierarchy, flow, relational, and pattern layouts. Sankey diagrams, treemaps, edge bundles, bin-packing, masonry, calendar grids, and more.

hylograph-layout

PureScript Type Classes

Type class hierarchies laid out with force-directed simulation, each class rendered as a Sigil card. The meta-level view of PureScript's type system.

sigil-hats
