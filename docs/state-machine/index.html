Glassbox — a machine is a file

Both machines below are JSON artifacts fetched at runtime. Nothing in this page was compiled to know that a guitar looper or a car radio exists: the same code loads either, runs it, and derives the drawing from the very same value it is running — so the picture and the program cannot disagree. Change a configuration setting and watch a state strand itself, which is the mechanical test for whether a setting belongs to the machine at all.
